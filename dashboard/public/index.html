TABLEAU INTEGRATION

Tableau Dashboard Connector & Big Data Architecture

The big data pipeline extracts multi-year historical prices from Hadoop HDFS, computes metrics via PySpark / MapReduce in parallel, and delivers a clean, partitioned dataset directly into Tableau Desktop / Tableau Server for visual storytelling.

Download Tableau Dataset (.CSV)

📁 1. Hadoop HDFS Cluster Storage

Raw historical stock OHLCV data stored across HDFS distributed blocks with 3x replication factor under /user/hadoop/stock_analytics/raw.

⚡ 2. PySpark Parallel Processing

PySpark Window functions partition by Ticker and calculate Daily Return, 50-day/200-day Moving Averages, and 50-day rolling Volatility in parallel.

📈 3. Tableau Dashboard Visualizations

Connect Tableau directly to processed_stock_analytics.csv to build interactive dual-axis trend lines, volatility heatmaps, and beta comparison scatter plots.
